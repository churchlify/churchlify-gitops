Sportif ML Factory — GitOps Implementation Prompt

You are implementing the Sportif ML Factory, a self-hosted, Kubernetes-native computer-vision training pipeline for the Sportif sports video platform.

The goal is to deploy a repeatable, auditable workflow that takes Sportif-owned soccer videos, extracts representative frames, allows human annotation, creates a validated dataset, trains a Sportif-owned soccer-ball detector from random initialization, evaluates it on unseen videos, exports the model to ONNX, and stores all model/dataset/provenance artifacts.

The implementation must integrate into the existing Sportif GitOps/Kubernetes infrastructure rather than creating a parallel platform.

12. DATASET SPLITTING

CRITICAL:

Never randomly split individual video frames into train/validation/test.

Split by SOURCE VIDEO.

For example:

Video 001 → TRAIN
Video 002 → TRAIN
Video 003 → TRAIN
Video 004 → VALIDATION
Video 005 → VALIDATION
Video 006 → TEST
Video 007 → TEST

This prevents temporal leakage.

The dataset generator must enforce this.

Recommended initial target:

70% train
15% validation
15% test

by video.

Make the split deterministic using a dataset seed.
